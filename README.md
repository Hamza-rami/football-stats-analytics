# ⚽ Football Data Analysis – Top 5 European Leagues

## 📌 Project Overview

This project explores player, squad, and league performance across the Top 5 European football leagues using data analysis techniques in Python.

The objective is to transform raw football statistics into meaningful tactical and performance insights through structured Exploratory Data Analysis (EDA).

---

## 🎯 Project Objectives

- Identify the most efficient goal scorers
- Analyze possession and ball control patterns
- Evaluate squad attacking efficiency
- Measure star dependency within teams
- Compare leagues by attacking and defensive strength

---

## 🛠 Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

---

## 🧹 Data Cleaning & Feature Engineering

The following steps were performed:

- Checked and handled missing values
- Verified numeric data types
- Removed duplicate entries
- Engineered new analytical features:

  - `Touch_per_Goals`
  - `Ball_Loss = Mis + Dis`
  - `Recovery_per_Touch`
  - `Star_Dependency_%`

---

## 📊 Analysis Sections

### 👤 Player-Level Analysis

- Top goal scorers
- Goals per touch (scoring efficiency)
- Most ball losses
- Most ball recoveries
- Progressive carries leaders

---

### 🏟 Squad-Level Analysis

- Total goals by squad
- Touches required per goal
- Star Dependency Index
- Squad ball balance (Recoveries − Ball Loss)
- Discipline analysis (Yellow & Red cards)

---

### 🌍 League-Level Analysis

- Total goals per league
- Defensive activity comparison
- Attacking efficiency comparison

---

## 📈 Key Insights

- Some squads required significantly fewer touches per goal, indicating high attacking efficiency.
- Certain teams showed strong dependency on a single top scorer.
- Defensive intensity varied across leagues.
- High possession does not always guarantee high scoring efficiency.
